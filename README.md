# Arshith Info-Tech

Empowering Digital Transformation, Cloud Engineering, and Next-Generation Technology Solutions.

## 🚀 Overview

Arshith Info-Tech is a modern enterprise technology website built with clean, responsive web standards, dynamic micro-animations, glassmorphism UI, and interactive modules.

### Features
- **Modern Hero Section**: Interactive particle canvas background, typewriter effect, and floating metric cards.
- **Core Capabilities & Services**: Interactive modal views detailing digital transformation, cloud computing, engineering & R&D, enterprise software, and infrastructure management.
- **Dynamic Stats & Counters**: Animated metric counters on scroll.
- **Domain Expertise**: Industry highlights across Financial Services, Healthcare, Manufacturing, and Retail.
- **Interactive Contact Form & Modals**: Smooth modals, validation, and feedback states.
- **Fully Responsive**: Mobile drawer menu and seamless cross-device layouts.

## 🛠️ Tech Stack
- **HTML5 & CSS3**: Vanilla CSS design system with custom properties and glassmorphism styling.
- **JavaScript (ES6+)**: IntersectionObserver for scroll reveals, canvas particle physics, typewriter, and interactive modals.
- **FontAwesome 6 & Google Fonts (Inter)**.

## 💻 Local Setup
1. Clone the repository:
   ```bash
   git clone https://github.com/VullasReddy/Arshith-Infotech.git
   cd Arshith-Infotech
   ```
2. Open `index.html` in your web browser or serve with Python:
   ```bash
   python -m http.server 3000
   ```
3. Visit `http://localhost:3000` in your browser.
